## Architecture Change

### Before (Complex)
```
Your Browser
├─ www.parkipal.com (frontend on Cloudflare)
│  └─ Calls api.parkipal.com (backend on Heroku)
└─ API subdomain + frontend domain = complexity
```

### After (Simple)
```
Your Browser
└─ parkinsons-pal.up.railway.app (everything)
   ├─ GET / → index.html
   ├─ GET /medications.html → file
   └─ POST /api/auth/login → server logic
   
One domain, one server, one database
```

## One More Time: What Changed?

**The ONLY architectural change:** 
- Frontend and backend on **same domain** instead of separate subdomains
- API stays at `/api/*` path
- Frontend served from Express root

**Why it matters:**
- ✅ Simpler (no CORS issues between subdomains)
- ✅ One provider (Railway handles everything)
- ✅ One deploy (push git → live)
- ✅ Cleaner URLs
- ✅ Better for small apps
